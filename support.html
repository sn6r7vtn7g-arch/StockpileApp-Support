宝宝囤 StockpileApp Support

宝宝囤是一款母婴囤货和宝宝日常记录工具，用于管理库存、补货提醒、宝宝档案、疫苗计划和家庭共享。

StockpileApp is a baby inventory and family care record app for managing household stock, restock reminders, baby profiles, lifestyle vaccine reminders, and iCloud family sharing.

常见问题

iCloud 同步：同一 Apple ID 的设备会自动同步；不同 Apple ID 的家庭成员需要通过家庭页发送 iCloud 共享邀请。

通知提醒：请在 iOS 系统设置中允许宝宝囤发送通知，以接收库存、疫苗和称重提醒。

疫苗计划：疫苗计划基于国家卫生健康委《国家免疫规划疫苗儿童免疫程序及说明（2021年版）》整理，适用于中国大陆的国家免疫规划生活提醒参考。实际接种请以当地接种门诊、接种证和医生建议为准；本功能不接入 HealthKit 或 CareKit。

相机/相册权限：相机用于拍摄宝宝头像和成长里程碑照片；相册用于选择头像、成长照片和视频。当前版本不提供扫码添加物品入口。

数据安全：核心数据保存在本机 Core Data，并可通过 Apple CloudKit 同步；电商链接导入会限制允许域名、关闭 Cookie，并限制响应大小。

高级功能：当前版本高级功能已开放使用，不展示真实购买入口。

HealthKit / CareKit / NFC：当前版本不使用 HealthKit、CareKit 或 NFC，也没有外部硬件配对流程。

远程通知边界：库存、疫苗、称重等用户提醒均由设备本地通知调度。本 App 不使用自建 APNs 服务端，也不保存 device token；iCloud 同步会使用 Apple CloudKit 所需的系统后台通知。

Frequently Asked Questions

iCloud sync: Devices signed in with the same Apple ID can sync automatically through iCloud. Family members using different Apple IDs need to accept an iCloud sharing invitation from the Family page.

Notifications: Please allow StockpileApp notifications in iOS Settings to receive local reminders for inventory, vaccine schedules, baby weight checks, and daily care tasks.

Vaccine schedule: The vaccine schedule is a lifestyle reminder based on the 2021 National Immunization Program schedule published by China's National Health Commission. It is intended as a reference for mainland China only. Actual vaccination timing should follow your local clinic, vaccination record, and doctor's advice. This feature does not use HealthKit or CareKit.

Camera and photo library permissions: Camera access is used only for taking baby profile photos and milestone photos. Photo library access is used only for selecting baby photos, milestone photos, and videos. The current version does not provide a barcode or QR-code item scanning entry.

Data safety: Core app data is stored with Core Data on the device and may sync through Apple CloudKit. E-commerce link import is limited to allowed domains, uses an ephemeral session without cookies, and limits response size. Please do not paste passwords, payment details, ID numbers, or other sensitive information into import text.

Premium features: Premium features are currently open in this review build. The app does not show a real purchase entry in this version.

HealthKit / CareKit / NFC: The current version does not use HealthKit, CareKit, CoreNFC, NFC tags, or any external hardware pairing workflow.

Remote notification boundary: User reminders for inventory, vaccine schedules, weight checks, and summaries are scheduled locally on the device. The app does not operate a custom APNs server and does not store device tokens. iCloud sync may use Apple CloudKit system background notifications required by Apple's CloudKit framework.
